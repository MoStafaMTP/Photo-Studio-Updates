# Photo Studio for Windows

Official installers and update files for Photo Studio.

## Install or update

Download the Setup.exe from [the latest release](https://github.com/MoStafaMTP/Photo-Studio-Updates/releases/latest), or use **Help -> Check for updates** in Photo Studio 1.0.4 or newer. Export open work before restarting. Saved watermarks and an existing verified background-removal model are retained.

Versions 1.0.3 and earlier should install the 1.0.4 transition update while the original update feed remains available. If an older version cannot find updates, download the latest installer here and install it over the existing application.

Windows x64. Fresh installations download the background-removal model during setup. See each release for signing and installation notes.

## Repository contents

This repository contains download documentation and release assets only. Application source development and Git history are maintained separately. Each release includes the installer, its blockmap, and latest.yml for the in-app updater.
